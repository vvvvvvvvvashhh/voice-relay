# Voice Relay

在 Devin 编辑器里，把 Devin 自带的语音输入转给 Claude Code 面板用。

## 用法

1. 点右下角状态栏「🎤 语音→Claude」，或按 `Ctrl+Alt+V`，开始说话（实际触发的是 Devin 的麦克风）。
2. 再按一次结束。转写完成后，文字会自动从 Devin 输入框移到 Claude 输入框。
3. 状态栏显示「转写中…」时再按会被忽略，等它回到「语音→Claude」再开始下一轮。

## 命令

- `语音输入（借 Devin 麦克风）`：开始/结束，默认快捷键 `Ctrl+Alt+V`。
- `Voice Relay: 重置状态`：按钮状态和 Devin 实际录音状态对不上时，把按钮复位为空闲。只改按钮显示，不会去按 Devin 的麦克风。

## 要求

- Devin 编辑器（需提供 `devin.cascade.pressMicrophone` 命令）
- Claude Code 扩展

## 设置

- `voiceRelay.timeoutMs`：停止录音后等待转写的最长时间，默认 15000 毫秒。

## 适用范围与已知边界

- **只能在 Devin 编辑器里使用**：依赖 Devin 提供的 `devin.cascade.pressMicrophone` 命令，在 VS Code 或其他编辑器里没有效果。
- **语音识别由 Devin 完成**：识别效果和隐私政策以 Devin 为准。本扩展不做识别，也不联网。
- **剪贴板**：
  - 中转时会临时借用剪贴板，完成后自动恢复原来的**文字**内容。原来复制的是图片或文件时恢复不了，会被清空。
  - 开着 Windows 剪贴板历史（`Win+V`）时，每次转写的文字会在历史里留下一条。
  - 等待转写的几秒内新复制的内容，会被恢复的旧内容覆盖。
- **录音状态不同步**：Devin 不对外提供「是否正在录音」的状态，扩展只能自己记。如果直接点了 Devin 的麦克风，或 Devin 自己停止了录音，按钮会显示错，用「重置状态」复位。
- **剪切依赖焦点**：取转写文字的方式是在 Devin 输入框里「全选 + 剪切」。
  - 如果转写期间焦点跑到了打开的文件里，扩展会发现文件被清空，立即把原内容写回并停止，转写文字留在 Devin 输入框里。被写回的文件可能显示为「未保存」，内容不变，按 `Ctrl+S` 即可。
  - 这层保护只覆盖当前可见的编辑器标签；焦点落在其他输入框（如搜索框、终端）时不做检查。
  - Devin 输入框里原本已有的文字，会和转写结果一起被移到 Claude。
- **不会出现在 Claude 面板输入框内**：入口只在状态栏。Claude Code 面板自带的麦克风按钮需要 claude.ai 账号登录，使用第三方 API 时不会显示，本扩展不改动它。
